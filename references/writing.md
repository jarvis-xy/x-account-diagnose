# 报告用词

对用户说话，用下面这套词。不要把内部黑话直接写进报告。

| 不要写 | 写成 |
|---|---|
| 声称的定位 / 定位梳理 | 账号个人简介；简介和实际发的内容对不对得上 |
| 回复当主业 | 把回复别人评论当成主要运营动作 |
| 和公式拧着 / 停掉和公式拧着的那一件事 | 停止和 X 开源推荐规则相违背的动作 |
| 整号限流 / 被阴了 | 整个账号被限制推荐 |
| 账号标 / 帖标 | 账号标签 / 帖子标签 |
| For You / 站外 | 推荐页（没关注你的人也能刷到） |
| 主粮 | 这个月主要在发什么 |
| 定罪 | 不能用这个月的标签判断另一个月 |
| 聚合到账号 | 帖子标签攒多了，可能变成整个账号的限制 |
| 不另起玄学 | 不另搞一套说不清的方法 |
| 风险识别 | 账号有没有被限制推荐 |
| 优化建议 | 下一步怎么改 |

Technical labels (`NSFW_HIGH_PRECISION` 等) can stay in tables. Add one plain-language line next to them.

Write the report in the user's language. If they write in English, use [report-template.en.md](report-template.en.md). If they write in Chinese, use [report-template.md](report-template.md).
